Windows 桌面工具：保存多个窗口的位置、显示器和启动方式，并可一键恢复工作布局。

支持多显示器定位、浏览器普通/访客/无痕模式、同一浏览器窗口的多个网址、已打开窗口捕获、布局导入导出、窗口追踪关闭和托盘运行。

## 下载与安装

从公开发布仓库的 [Releases](https://github.com/chhlll1998/window-layout-manager-releases/releases)
页面下载最新的 `WindowLayoutManager-Setup.exe`，双击安装即可。

完整使用方法请看 [用户手册.md](用户手册.md)。布局数据保存在本机，不会上传；换电脑时请先在软件中导出布局，再在新电脑导入。
