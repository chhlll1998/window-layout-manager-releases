# 窗口布局管理器 v1.1.0

1.1.0 新增本地用户管理：先选择用户，再选择该用户的布局。

Windows 桌面工具：保存多个窗口的位置、显示器和启动方式，并可一键恢复工作布局。

支持多显示器定位、浏览器普通/访客/无痕模式、同一浏览器窗口的多个网址、已打开窗口捕获、布局导入导出、窗口追踪关闭和托盘运行。

## 下载与安装

从 [Releases](https://github.com/chhlll1998/window-layout-manager-releases/releases)
页面下载最新的 `WindowLayoutManager-Setup-v1.1.0.exe`，双击安装即可。

完整使用方法请看 [用户手册.md](用户手册.md)。布局数据保存在本机，不会上传到 GitHub；换电脑时请先在软件中导出布局，再在新电脑导入。

## v1.1.0 更新

- 新增本地用户管理和用户分组，可为不同用户分别管理布局；用户与布局数据仅保存在本机；
- 新增窗口刷新：右键任一窗口选择“刷新窗口”即可预览并同步位置、大小；浏览器窗口还会同步网址，读取不完整时只补充、不删除；3秒后捕获浏览器窗口会尝试读取全部标签页；
- 新增顶部工具栏最右侧“导出日志”，可导出环境、屏幕、布局、窗口追踪和完整日志用于排查问题；
- 新增“关闭当前布局”，并移除独立的“关闭前一布局”菜单项；
- 优化多选删除和关闭确认清单，确认列表支持滚轮滚动且去除不自然的滚动条边线；
- 修复底部日志框无法使用鼠标滚轮上下滚动的问题；
- 延续 1.0.4 的浏览器多网址编辑、更新流程和界面布局优化。
