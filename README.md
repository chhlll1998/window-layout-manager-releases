# 窗口布局管理器 v1.1.0

Windows 桌面工具，保存多个窗口的位置、显示器和启动方式，并可一键恢复工作布局。

支持多显示器定位、浏览器普通/访客/无痕模式、同一浏览器窗口的多个网址、已打开窗口捕获、布局导入导出、窗口追踪关闭和托盘运行。

## 下载与安装

从 [Releases](https://github.com/chhlll1998/window-layout-manager-releases/releases/latest) 页面下载最新的 [`WindowLayoutManager-Setup-v1.1.0.exe`](https://github.com/chhlll1998/window-layout-manager-releases/releases/latest/download/WindowLayoutManager-Setup-v1.1.0.exe)，双击安装即可。

完整使用方法请看 [用户手册.md](用户手册.md)。布局数据保存在本机，不会上传到 GitHub；换电脑时请先在软件中导出布局，再在新电脑导入。

## v1.1.0 更新

- 新增本地用户管理：先选择本地用户，再选择该用户的布局；
- 新增窗口刷新：右键任一窗口选择“刷新窗口”即可预览并同步位置、大小；
- 新增顶部工具栏“导出日志”功能；
- 新增“关闭当前布局”；
- 优化多选删除和关闭确认流程；
- 修复底部日志框滚动问题；
- 修复窗口列表和布局管理窗口的列宽拖动问题；
- 优化窗口大小调整时的响应速度。
