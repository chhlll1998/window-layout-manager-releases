# 窗口布局管理器 v1.1.2

Windows 桌面工具：保存多个窗口的位置、显示器和启动方式，并可一键恢复工作布局。

支持多显示器定位、浏览器普通/访客/无痕模式、同一浏览器窗口的多个网址、已打开窗口捕获、布局导入导出、窗口追踪关闭和托盘运行。

## 下载与安装

从[Releases](https://github.com/chhlll1998/window-layout-manager-releases/releases)
页面下载最新的 `WindowLayoutManager-Setup-v1.1.2.exe`，双击安装即可。

完整使用方法请看 [用户手册.md](用户手册.md)。布局数据保存在本机，不会上传到 GitHub；换电脑时请先在软件中导出布局，再在新电脑导入。

## v1.1.2 更新

- 一键捕获确认窗口中的浏览器项目支持右键“编辑窗口”，可直接调整名称、全部网址、浏览器模式、显示器和位置；
- 支持右键“重新读取标签页和浏览器模式”，更新当前捕获项目并恢复原活动标签页；
- 支持右键“查看完整网址”，在独立只读窗口中检查全部网址；
- 支持右键“恢复捕获内容”，撤销本次确认窗口中的编辑和重新读取；
- 删除浏览器网址时保留当前滚动位置；删除末尾网址后仍停留在列表底部，不会跳回第一行；
